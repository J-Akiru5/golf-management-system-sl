## 5. What works, with evidence

- **The whole gate is in the database, not the page.** A held lane answers a direct RPC with no name
  and no score (`supabase/migrations/20261115000200_results_reveal.sql:95-125`), and the other
  surfaces are gated by `publish_allows` inside the read functions
  (`supabase/migrations/20261110000100_public_release_enforcement.sql:64-108`, `:154`, `:211`).
- **Blackout reaches the wall.** `/tv` reads the release keys first and polls every 5 seconds while it
  shows scores (`src/app/(display)/tv/page.tsx:42-58`, `:101`); `/roster`, `/results/all` and
  `/leaderboard` each return a holding screen without asking for a score
  (`roster/page.tsx:62-78`, `results/all/page.tsx:56-78`, `leaderboard/page.tsx:107-133`).
- **The countdown cannot be gamed by a phone clock.** Remaining time is measured from the server's
  render time plus elapsed local time (`src/lib/public/results-reveal.ts:370-395`).
- **Public reads are allow-listed functions, and the anon client cannot do more.** The public client
  uses the anon key only (`src/lib/supabase/public.ts:10-16`), and the migrations revoke anon execute
  and make new functions private by default
  (`supabase/migrations/20261030000000_revoke_anon_execute.sql`,
  `20261031000000_private_functions_by_default.sql`).
- **The service role never reaches a browser.** It is read only in server modules and scripts
  (`src/lib/scorecards/store.ts:92`, `src/lib/scorecards/field.ts:169`, and the one-off scripts under
  `scripts/`); all nine files under `src/app/api/scorecards` that touch it call `requireScorecardAccess`
  (`grep -l requireScorecardAccess src/app/api/scorecards` lists every route file), and that check
  refuses a signed-out caller and an account that is neither staff nor tabulation
  (`src/lib/scorecards/access.ts:47-84`).
- **No credential is in the repository.** `git grep` for `sk-…`, a JWT-shaped string, or
  `PASSWORD=` found only code identifiers; `.env*` is ignored except `.env.example`
  (`.gitignore:6-7`), which carries names and no values (`.env.example:1-63`).
- **Two-consent photos.** A public photo needs its own consent, and the code refuses to write one
  without the token column (`src/lib/data/supabase/players.ts:183-204`).
- **Player cards are frozen snapshots.** The public profile and leaderboard read published rounds only
  (`src/lib/data/public-results.ts`, `public_player_scorecard` in
  `20261114000400_public_profile_playing_handicap.sql:37-52`), so a live edit cannot change a public
  score.
- **Fonts and assets are bundled.** No `next/font`, `fonts.googleapis.com` or CDN reference anywhere in
  `src` or `public`; the font packages are `@fontsource` dependencies in `package.json`.
- **A publish clears the public cache.** Every writer calls `refreshPublicPage`, proved with a fake
  cache and a fake database in `src/lib/data/supabase/public-cache.test.ts`
  (`docs/PLAN.md:445`).
- **The demo awarding flag cannot reach production.** `src/lib/public/awarding-demo.ts:30-35` refuses
  `VERCEL_ENV=production` before it looks at anything else.
